# Production Giant

Личный планировщик производства для EVE Online в духе EVE Guru: цепочки сборки (T1/T2/T3, капиталы, реакции), цены Jita, стоимость джоб, прибыль. Работает локально, для одного пользователя.

План: [`docs/plan.md`](docs/plan.md) · решения: [`docs/decisions.md`](docs/decisions.md)

## Установка (один раз)

Нужны **Node.js 22 LTS** (подойдёт 20–24) и **Git**.

```bash
git clone https://github.com/sedrionn/production_giant.git
cd production_giant
npm install
npm run db:migrate        # создаёт data/app.sqlite с пресетами структур
npm run sde:download      # качает официальный SDE (~сотни МБ) и собирает data/sde.sqlite
```

`sde:download` в конце печатает количество типов и чертежей. Если видишь `SANITY CHECK FAILED`, скопируй вывод целиком и пришли в сессию: значит, CCP поменяли формат.

## Снять фикстуры (после каждого обновления SDE или раз в пару недель)

```bash
npm run fixtures:capture
git add fixtures && git commit -m "Update fixtures" && git push
```

Это реальные данные (дерево Jackdaw, R.A.M., Hammerhead II, капитальный компонент, реакция + цены Jita). По ним облачные сессии и тесты работают без доступа к ESI. Свои предметы можно передать аргументами: `npm run fixtures:capture -- "Hammerhead II" 34828`.

## Запуск

Двойной клик по **`start.cmd`** в папке проекта: сервер запустится, браузер откроется сам. Остановить — закрыть окно или Ctrl+C.

Двойной клик по **`update.cmd`**: подтянуть свежий код из main, поставить зависимости, обновить базу и запустить приложение.

Вручную то же самое: `npm run dev` → http://localhost:3000

- **Калькулятор** (`/`): выбери предмет, раны, ME/TE, чертёж (свой или инвент), структуры и режимы цен. Кнопка «строить / купить» в дереве переключает решение для узла, правый клик возвращает авто. «Обновить цены» тянет свежие цены из ESI для всего дерева.
- **Структуры и настройки** (`/presets`): пресеты (тип, зона, система для cost index, риги, налог), налоги рынка, скиллы, ME/TE компонентов.

После обновления кода, где менялся импорт SDE, пересобери базу: `npm run sde:download -- --force`.

## Персонажи (EVE SSO)

Один раз:
1. На [developers.eveonline.com/applications](https://developers.eveonline.com/applications) создай приложение типа «Authentication & API Access».
2. Callback URL: `http://localhost:3000/api/auth/callback`.
3. Скоупы: `esi-skills.read_skills.v1`, `esi-characters.read_blueprints.v1`, `esi-industry.read_character_jobs.v1`, `esi-assets.read_assets.v1`, `esi-corporations.read_blueprints.v1`, `esi-industry.read_corporation_jobs.v1`, `esi-assets.read_corporation_assets.v1`, `esi-wallet.read_character_wallet.v1`, `esi-markets.read_character_orders.v1`, `esi-contracts.read_character_contracts.v1`.
4. Создай в корне проекта `.env.local`:
   ```
   EVE_CLIENT_ID=...
   EVE_CLIENT_SECRET=...
   ```
5. Перезапусти `npm run dev`, на странице «Персонажи» нажми «Добавить персонажа» и залогинься. Альтов добавляй так же по одному.

Refresh-токены хранятся зашифрованными в `data/app.sqlite`, ключ лежит в `data/secret.key` (не коммитится). Корпоративные чертежи видны только персонажу с ролью Director, корп. джобы — с ролью Factory Manager.

## Обзор «Что выгодно»

Категории: мои чертежи, Калдари T1/T2, T3, реакции, риги T1/T2. По каждому предмету считается полное дерево, а партия подбирается так, чтобы джоба продукта шла около N дней (настройка). Цены Jita и историю продаж тянет кнопка «Обновить всё» в шапке, это может занять пару минут.

## План недели и учёт

- **План недели** (`/plan`): бюджет и как часто заходишь в игру; план всегда на 7 дней. Корпуса этой недели идут из того, что есть на складе, компоненты — под следующую неделю (первая неделя с пустым складом — разгон). Закрепы — в штуках, с выбором чертежа и декриптора. Получаешь расписание по заходам (кто что ставит), один список закупки, лист кандидатов для Claude и файл `.ics` для календаря.
- **Учёт** (`/ledger`): сколько потрачено и заработано, что построено и продано, перебитые ордера. Нужны скоупы кошелька, ордеров и контрактов: добавь их в приложение на developers.eveonline.com и перезайди персонажами.
- Пока приложение запущено, персонажи и цены обновляются сами раз в сутки. Вручную — кнопка «Обновить всё» в шапке (персонажи → индексы → цены → объёмы → пересчёт плана).

## Разработка

```bash
npm test                  # Vitest
npm run typecheck
npm run lint
```

| Папка | Что там |
|---|---|
| `src/engine` | чистый движок расчёта (без IO — проверяется линтером) |
| `src/sde` | импорт и доступ к SDE (`SdeSource`: SQLite или фикстуры) |
| `src/esi` | клиент ESI и преобразования ответов |
| `src/db` | схема Drizzle, сиды |
| `scripts` | `sde-download`, `fixtures-capture`, `db-migrate` — **запускаются локально** |
| `fixtures` | коммитящийся срез реальных данных для тестов |
| `data` | локальные БД, в git не попадают |
